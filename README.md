# Main Challenge: Ashwas AI 2.0

## Overview
Ashwas AI 2.0 is a multi-modal, GenAI-powered recovery platform providing evidence-based support.

## Architecture
- `main.py`: FastAPI entry point.
- `/core`: AI Engine, Safety, and Risk Prediction.
- `/services`: Business logic (Chat, Emergency, Education).
- `/api`: REST API endpoints.

## Setup
1. `pip install -r requirements.txt`
2. Create `.env` from `.env.example`.
3. `python main.py`
